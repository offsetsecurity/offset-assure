# Roadmap: Offset Assure

What is coming next. Dates are the quarter we plan to ship in.

## Done

- **October 2026:** a Reports tab, and an executive summary for management.
- **October 2026, 0.2.46:** fixes from our white-box security audit. Non-Latin file
  names download, sign-in no longer hints which usernames exist, components
  updated, smaller Docker images.
- **October 2026, 0.2.47:** Docker installs keep evidence files across updates,
  and can keep their data in a folder you choose.

- **November 2026:** the step-by-step plan (now called Plan) has a new look, with a
  "Run a mock audit" button at the top where it is easy to see; every screen has the
  new look; Settings is one page of tabs with an Overview.

## Planned for Q1 2027

- **Multi-factor sign-in.** A code from an authenticator app at sign-in, with
  backup codes for a lost phone and an administrator reset. It works fully
  offline, like the rest of the product.
- **More reports.** New reports in the Reports tab, each grouped by who it is
  for, with a preview before you download.
